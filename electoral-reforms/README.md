# 選挙制度の変更（1945年〜）

戦後の衆議院・参議院の選挙制度と投票のしかたの主な変更（女性参政権、比例代表制、小選挙区比例代表並立制、投票時間の延長、期日前投票、18歳選挙権など）を、法令の施行日で並べた年表。

## 注記

- 点の位置は法令の施行日。施行日を確かめられなかった1945年の衆議院議員選挙法の改正と1994年の小選挙区比例代表並立制は公布日に、根拠の法令を確かめられなかった1974年の投票時間の延長は投票日に置いた。
- 施行日のうち、附則に「公布の日から起算して…を経過した日から施行する」とあるものは、その定めから数えた日付。
- 両院にかかわる変更は、院ごとに初めて適用した選挙が違う。初めて適用した選挙は、総務省の投票率の資料の注記、各法律の附則、選挙の日付から確かめた。
- 1963年と1974年の投票時間の延長は、その選挙だけのもの。1974年の延長（1時間延長、午後7時まで）は、総務省の投票率の資料の注記による。
