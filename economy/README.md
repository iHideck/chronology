# ドル円・日経平均・消費者物価

1949年から2025年までの、ドル円の為替相場（年平均）、日経平均株価（年末の終値）、消費者物価の上がり方（前年比）を、景気の拡張期・後退期と総理大臣と同じ時間軸に並べた年表です。1ドル360円の固定相場の終わり（1971〜1973年）、石油危機のあとの物価の上昇（1974年）、バブルの最高値（1989年末）、リーマン・ショックのあとの下落（2008年）の位置が読めます。

## 注記

- ドル円と消費者物価は年の値なので、その年の真ん中の高さに点を置いた。日経平均は年末の終値なので、その年の終わりの高さに置いた。
- ドル円は1ドルあたりの円の年平均。1955〜2024年は内閣府の長期経済統計の円相場、2025年は内閣府「月例経済報告」の主要経済指標の円相場で、どちらもインターバンク直物中心レートの営業日平均。
- 内閣府の表は、1970年までを固定相場の360円としている。1950〜1954年は、統計局「日本の長期統計系列」にある年末の基準相場の360円。固定相場なので、年の途中も同じ値。
- 1949年のドル円は、年平均を載せた資料が見つからないため空欄。
- 日経平均株価は、その年の最後の取引日の終値。東京証券取引所が1950年9月7日に算出を始め、取引を再開した1949年5月16日までさかのぼって計算した。1949年は5月16日からの値。
- 消費者物価は、消費者物価指数の年平均の前年比で、総務省統計局の2025年基準の長期時系列データの値。前年比は、それぞれの基準のときに公表した値で、つないだ指数から計算し直したものではない。
- 1971年からは「総合」、1970年までは「持家の帰属家賃を除く総合」の前年比。統計局は、持家の帰属家賃を含む指数を1970年基準で参考の系列として作り始め、1985年基準で総合にした。内閣府の長期経済統計も、同じ年でつないでいる。
- 1971〜1985年の当時の総合指数は、帰属家賃を除く総合だった。そのため当時の発表と違う年があり、1974年は全国が23.2%（当時の総合指数では24.5%）、東京都区部が21.2%（同22.7%）。
- 全国の指数は、1962年以前は人口5万以上の市の指数をつないだもの。沖縄県を含むのは1975年基準から。
