## 注記

- 朝鮮王朝・大韓帝国の君主（高宗・純宗）と、大韓民国の大統領を並べた。朝鮮民主主義人民共和国（北朝鮮、1948年9月9日成立）の指導者は含めない。
- 日付はすべてグレゴリオ暦。朝鮮は旧暦1895年11月17日を1896年1月1日として太陽暦に改めたので、それより前の旧暦の日付はグレゴリオ暦に直した。高宗の即位は旧暦1863年12月13日で、グレゴリオ暦では1864年1月21日（先王の哲宗の死去は旧暦12月8日＝1月16日）。
- 高宗は、朝鮮国王（1864〜1897年）と大韓帝国皇帝（1897〜1907年）の在位を1本にまとめた。1897年10月12日に圜丘壇で皇帝に即位し、翌13日に国号を大韓と宣布した（大韓帝国）。
- 高宗の退位（純宗の即位）は、皇太子に政務を代理させる詔勅が出た1907年7月19日とする出典（韓国語版・英語版 Wikipedia）と、譲位式のあった7月20日とする出典（日本語版 Wikipedia、韓国民族文化大百科事典）がある。ここでは7月20日とした。
- 1910年8月29日の韓国併合から1945年までの日本の統治（朝鮮総督府）の期間は、年表に入れていない。1919年に上海で樹立された大韓民国臨時政府（初代大統領は李承晩）も入れていない。
- 1945年8月15日の日本の降伏後、北緯38度線の南では、9月8日に上陸した米軍が9月9日に朝鮮総督府の降伏を受け、在朝鮮アメリカ陸軍司令部軍政庁（米軍政）が1948年8月15日の大韓民国政府の樹立まで統治した。この期間も年表に入れていない。李承晩は政府樹立の宣布より前の1948年7月24日に大統領に就任したので、米軍政の最後の3週間と重なる。
- 大韓民国の大統領は、就任した日から退任した日（任期満了・辞任・死去・罷免の日）まで。任期満了の退任日は任期の最終日（例：盧泰愚は1993年2月24日）で、次の大統領は翌日に就任している。同じ人が続けて務めた代（李承晩の第1〜3代、朴正煕の第5〜9代、全斗煥の第11〜12代）は1本にまとめ、「代」に書いた。
- 国会や統一主体国民会議で選ばれた大統領は、選ばれた日と就任式の日がずれる。李承晩（1948年7月20日に選出、24日に就任）、尹潽善（1960年8月12日に選出、13日に就任）、全斗煥（1980年8月27日に選出、9月1日に就任）は就任した日にした。崔圭夏は、大統領権限代行のまま1979年12月6日に選ばれ、その日から大統領として職務を行ったので（就任式は12月21日）、12月6日にした。韓国語版・英語版 Wikipedia の一覧は、全斗煥の就任を選出の8月27日としている（韓国語版は尹潽善も選出の8月12日）。
- 李承晩の辞任は、下野を表明した1960年4月26日とする出典（日本語版 Wikipedia）もあるが、国会に辞表を出して受理された4月27日にした（英語版・韓国語版 Wikipedia）。
- 尹潽善の退任と朴正煕の大統領権限代行の始まりは、尹潽善が辞意を表明した1962年3月22日とする出典（日本語版・韓国語版 Wikipedia の大統領一覧、国家記録院の年表）と、朴正煕が権限代行に就いた3月24日とする出典（英語版 Wikipedia、日本語版 Wikipedia「国家再建最高会議」）がある。ここでは3月24日で区切った。
- 1961年5月16日の軍事クーデター（5・16軍事クーデター）から1962年3月24日までは、大統領は尹潽善のままだったが、実権はクーデターを主導した朴正煕と国家再建最高会議（軍事政権）にあった。この期間の朴正煕を、事実上の最高指導者として尹潽善と並べるため外側の段に置き、「推定・諸説あり」とした（国家再建最高会議の議長に就いたのは1961年7月3日で、それまでの議長は張都暎）。
- 1960年8月〜1961年5月の第二共和国は議院内閣制で、行政の実権は国務総理の張勉にあり、大統領の尹潽善は儀礼的な元首だった。年表は大統領で通した。
- 大統領権限代行は年表に入れていない（資料によって1日ほどずれる）。1960年4月27日〜8月12日は許政（首席国務委員、6月15日から国務総理。韓国語版・英語版 Wikipedia では、このうち6月16〜23日は民議院議長の郭尚勲、8月8〜12日は参議院議長の白楽濬が代行したとする）。1979年10月26日〜12月6日は崔圭夏（国務総理）。1980年8月16日〜9月1日は朴忠勲（国務総理代理。韓国語版・英語版 Wikipedia の一覧は8月27日まで）。2004年3月12日〜5月14日は高建（国務総理）。2016年12月9日〜2017年5月10日は黄教安（国務総理）。2024年12月14日〜27日は韓悳洙（国務総理）、2024年12月27日〜2025年3月24日は崔相穆（副総理兼企画財政部長官）、2025年3月24日〜5月1日は再び韓悳洙、2025年5月2日〜6月4日は李周浩（副総理兼教育部長官）。
- 1962年3月24日〜1963年12月16日の朴正煕の大統領権限代行（国家再建最高会議議長として）は、大統領の在任と1本にまとめた。
- 弾劾訴追で職務が停止された期間（盧武鉉・朴槿恵・尹錫悦）は在任期間に含め、「職務停止」に期間を書いた。
- 読みは、韓国語の発音のカタカナ表記（日本語版 Wikipedia の表記に合わせた。例：李承晩＝イ・スンマン）。
- 2025年6月3日の大統領選挙（尹錫悦の罷免を受けた選挙）で李在明が当選し、6月4日に就任した。2026年10月31日の時点で、李在明が在任中。
