# 日本の人口と出生数

1872年（明治5年）から2025年までの、日本の総人口と、毎年生まれた子どもの数（出生数）を、戦争や大きな出来事と同じ時間軸に並べた年表です。出生数は、1949年と1973年の2つの山と、丙午（ひのえうま）の1966年の谷を経て、2025年には67万人に減りました。総人口は2008年がいちばん多く、その後は減っています。

**動く版：[ihideck.github.io/chronology/population](https://ihideck.github.io/chronology/population/)**　データ：[population.csv](population.csv)（[書き方](../README.md#年表の足し方)）

## 注記

- 年ごとの値は、その年の真ん中の高さに点を置いて線でつないだ。総人口は、資料の時点（1月1日や10月1日）にかかわらず、その年の値として描いた。
- 総人口は千人単位。1872〜1919年は内閣統計局の推計で、各年1月1日現在（1872年だけ太陰暦1月29日、太陽暦3月8日現在）。内地（当時の日本の本土）にいる日本国籍の人の人口で、内地の外にいる軍人・軍属も含む。
- 1920年からは10月1日現在の、日本人と外国人を含む総人口。国勢調査の年は国勢調査の人口、ほかの年は国勢調査をもとにした推計人口（人口推計）。1945年だけは11月1日現在。1920年の1月1日現在の推計（55,473千人）は備考に書いた。
- 1940年は国勢調査の人口から海外にいた軍人・軍属の推計を引いた補正人口、1945年は人口調査の人口に軍人・軍属と外国人の推計を加えた補正人口、1947年は臨時国勢調査の人口に水害地の調査もれの推計を加えた補正人口。
- 総人口の範囲は、1920〜1944年が沖縄県を含む47都道府県で、朝鮮・台湾・樺太を含まない。1945年からは日本の行政権が及ぶ地域で、1945〜1969年は沖縄県を含まず、1970年から含む（1970年は含まない値が103,720千人）。十島村・奄美群島・小笠原諸島は、復帰後の最初の10月1日（1952・1954・1968年）の値から加えた。国勢調査の年（1950・55・60・65年）の沖縄県を含む人口は載せていない。
- 2021〜2024年は令和2年国勢調査を基準にした推計で、令和7年国勢調査にあわせた補正はまだない。2025年は令和7年国勢調査の人口（122,972,528人を千人未満で四捨五入）で、令和2年国勢調査を基準にした推計は123,219千人。
- 出生数は、厚生労働省の人口動態統計（確定数）の出生数で、対象は日本における日本人（1899年から）。1872〜1898年は、人口動態統計が始まる前の内閣統計局の値で、統計局「日本の長期統計系列」による。1872年は太陰暦2月1日から12月2日までの分。
- 出生数の範囲は、1947〜1972年が沖縄県を含まず、1973年から含む。1944〜1946年は戦災による資料喪失などで資料がなく、空欄。
- 合計特殊出生率は、人口動態統計の期間合計特殊出生率（15〜49歳の女性の年齢別出生率の合計）。公表されている1947年からで、1946年以前は空欄。1947〜1972年は沖縄県を含まない。
- 2025年の出生数は確定数（2026年9月30日公表）。合計特殊出生率は概数で、令和7年国勢調査の人口で計算し直す確定数（2026年11月公表予定）では変わる可能性がある。
- 第1次ベビーブーム（1947〜1949年）、第2次ベビーブーム（1971〜1974年）、丙午（1966年）の呼び方は、厚生労働省の人口動態統計月報年計（概数）の概況の図による。各年の備考に目印を書いた。
- ほかの列の定義・注記・出典は、それぞれの年表に載せています：[戦争・大きな出来事（1868年〜）](../events/)
