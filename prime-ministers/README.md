# 歴代総理大臣と世界の首脳

1868年（明治元年）から今日までの、日本の内閣総理大臣の在任期間を、顔写真つきで、アメリカ・中国・ソ連／ロシア・イギリスの首脳や、自民党総裁、景気の波、大きな出来事と同じ時間軸に並べた年表です。

**動く版：[ihideck.github.io/chronology/prime-ministers](https://ihideck.github.io/chronology/prime-ministers/)**　名前にカーソルを合わせると、在任日数や同じ時期の各国の首脳が出ます。

## 見かた

- 中央の帯が西暦と和暦、左が日本の内閣総理大臣（とその内側に自民党総裁・景気）、右が各国の首脳と出来事です。上から下へ時間が流れます。
- 棒の長さが在任期間です。同じ人が続けて務めた代（例：吉田茂の第48〜51代）は1本にまとめています。
- 総理の棒の切れ目は、臨時兼任・臨時代理の期間です。
- 下の画像はデータを更新した日の時点のものです（出来事の列は省いています）。動く版では、在任中の棒がページを開いた日まで伸び、表示する列を切り替えられます。

データ：[prime-ministers.csv](prime-ministers.csv)（総理）、[../us-presidents](../us-presidents/)・[../events](../events/) など（ほかの列）

## 注記

- 在任中の棒と在任日数は、ページを開いた日まで伸ばして表示しています。
- 明治への改元（1868年10月23日）より前の1868年も、明治元年として表示しています。
- 同じ人が続けて務めた代（例：吉田茂の第48〜51代）は1本の棒にまとめています。
- 総理の棒の切れ目は、臨時兼任・臨時代理の期間です。
- 総理の在任日数は、首相官邸の数え方（就任日と退任日を両方含む）です。
- ほかの列の定義・注記・出典は、それぞれの年表に載せています：[自由民主党総裁](../ldp-presidents/)、[日本の景気循環](../business-cycles/)、[歴代アメリカ合衆国大統領](../us-presidents/)、[中国の最高指導者](../china-leaders/)、[ロシア・ソ連の最高指導者](../russia-leaders/)、[イギリスの君主](../uk-monarchs/)、[戦争・大きな出来事（1868年〜）](../events/)
