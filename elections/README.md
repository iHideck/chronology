# 国政選挙と投票率

1946年からの衆議院議員総選挙と参議院議員通常選挙を、総理大臣や選挙制度の変更と同じ時間軸に並べた年表です。棒は選挙で決まった議席が続いた期間で、衆議院は解散まで、参議院は次の通常選挙までです。棒の色の部分は与党の議席の割合で、縦の線は過半数と3分の2です。折れ線は投票率です。

## 注記

- 投票率は総務省の資料の値。衆議院は大選挙区・中選挙区・小選挙区、参議院は地方区・選挙区の投票率で、比例代表や全国区の投票率ではない。
- 棒は、その選挙で決まった議席が続いた期間。衆議院は解散の日まで（任期満了だった第33回は次の総選挙の投票日まで）、参議院は次の通常選挙の投票日まで。解散から総選挙までは、衆議院の棒が途切れる。
- 衆参同日選挙（1980年と1986年）は、総務省の資料の注記による。
- 投票率の点は投票日に置き、同じ院の点を線で結んだ。線は、選挙と選挙のあいだの投票率を表すものではない。
- 与党は、党として政権に加わり、閣僚を出した党。衆議院は選挙のあとに最初にできた内閣、参議院は投票日の内閣で決めた。閣外協力の党、閣僚を出していない連立相手、所属議員が閣僚になっただけの会派（初期の緑風会）は与党の議席に入れず、「閣外協力など」に書いた。
- 衆議院の与党の議席は、その総選挙の党派別当選人数（公認の当選者の数）。選挙のあとの追加公認や会派入りは数えていない。衆議院の定数は、その総選挙で選んだ議員の数。
- 参議院の与党の議席は、選挙後の参議院全体（非改選を含む）の数で、選挙後最初の国会の召集日の会派別所属議員数。第14回以降は、議長・副議長が会派を離れたあとの数。「改選での与党の議席」は、その通常選挙の党派別当選人数。
- 選挙と選挙のあいだの連立の組み替えや議員の移動は、与党の議席に反映していない。
- 回ごとの出典と、資料による数の違いなどの注意は、CSV の「議席の出典」「議席のメモ」の列にある。
- ほかの列の定義・注記・出典は、それぞれの年表に載せています：[歴代総理大臣と世界の首脳](../prime-ministers/)、[選挙制度の変更（1945年〜）](../electoral-reforms/)
