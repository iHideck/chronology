## 注記

- 清は皇帝の在位期間。日本語版・英語版 Wikipedia に合わせて、即位式の日から数えた。先帝はそれぞれ1861年8月22日（咸豊帝）、1875年1月12日（同治帝）、1908年11月14日（光緒帝）に死去しており、先帝の死去から即位式までは空白になる。
- 1912年は、清（宣統帝の退位は2月12日）と南京の中華民国臨時政府（孫文が1月1日に臨時大総統に就任）が重なる。孫文は3月10日に袁世凱が臨時大総統に就いたあと、4月1日に正式に退任したので、孫文と袁世凱も3週間重なる。
- 1912〜1928年の中華民国は、南京の臨時政府の孫文と、そのあと国際的に認められていた北京政府の元首（臨時大総統・大総統・臨時執政・陸海軍大元帥）を入れた。大総統がいない間に国務院（国務総理）が職権を代行した期間も、代行した人を1人ずつ入れた。広州などにあった南方の政府（孫文の軍政府、1925年からの国民政府など）は入れていない。
- 1912〜1928年の日付は、政府公報などを出典にしている日本語版 Wikipedia「中華民国の元首」に合わせた。英語版とは、孫文の退任（英語版は3月10日）、黎元洪の辞任と馮国璋の代理就任（英語版はどちらも1917年7月17日）、顔恵慶から杜錫珪への交代（6月22日）、顧維鈞の退任（6月17日。英語版には2日間の胡惟徳がない）、張作霖の終わり（英語版は死去の6月4日）がずれる。黎元洪は7月6日に馮国璋に職務の代行を頼み、7月14日に正式に辞任したので、2人の期間は8日重なる。
- 袁世凱は1915年12月12日に皇帝に即位すると宣言し（中華帝国）、1916年3月22日に帝政を取り消した。この間も袁世凱の1本にまとめた。1917年7月1〜12日の張勲復辟（宣統帝の一時的な復位）は年表に入れていない。
- 1928年からの国民政府は蒋介石を中心にした。蒋介石は、国民政府主席に就いた1928年10月10日から、総統を退いた（引退した）1949年1月21日までを1本にした。この間の1931年12月15日〜1943年8月1日は林森が国民政府主席（政治的な実権のない元首）だったが、蒋介石が軍事委員会委員長（1932年3月6日〜1946年5月31日）・行政院長・国民党総裁（1938年から）として実権を握っていたので、蒋介石の期間に含めた。1931年12月15日に国民政府主席を辞めて（下野）から軍事委員会委員長に就くまでの約3か月も含めている。
- 蒋介石の前の国民政府主席の譚延闓（1928年2月7日〜10月10日）は、6月3日まで北京政府の張作霖と時期が重なるが、そのまま入れた。
- 1949年1月21日からは代理総統の李宗仁とした。代理総統の任期は1950年3月1日まで続いたが、1949年以降の台湾の中華民国は含めないので、中華民国政府が台北への移転を決めた1949年12月7日で打ち切った。1949年10月1日からは中華人民共和国の毛沢東と重なる。
- 中華人民共和国は事実上の最高指導者で、日本語版 Wikipedia「中華人民共和国の最高指導者一覧」の区切りに合わせた。
- 華国鋒は、党主席に就いた1976年10月7日から、鄧小平が実権を握った第11期三中全会の閉幕（1978年12月22日）まで。毛沢東の死去（1976年9月9日）からとする見方（英語版 Wikipedia など）もあるので「推定・諸説あり」とした。党主席は1981年6月まで続けた。
- 鄧小平は、1978年12月22日から、党中央軍事委員会主席を江沢民に譲った1989年11月9日まで。党の主席・総書記には就かず、党中央軍事委員会主席などとして実権を握った。江沢民が総書記に就いた1989年6月24日で区切る見方（英語版 Wikipedia）や、引退後も1997年に死去するまで最高実力者だったとする見方もあるので、鄧小平と江沢民を「推定・諸説あり」とした。
- 江沢民から胡錦濤、胡錦濤から習近平への交代は、党総書記の交代の日（2002年11月15日、2012年11月15日）にした。江沢民は党中央軍事委員会主席を2004年9月19日まで続けた。
- 2026年10月30日の時点で、習近平が在任中。
- 1949年の李宗仁（中華民国の代理総統）は、同じ年に成立した中華人民共和国と並べるため外側の段に置いています。
