## 注記

- 開始日は自民党公式サイト「自民党の歴史」に載っている各総裁の在任期間の初日で、日本語版 Wikipedia の各人物の記事の基礎情報とも一致する。多くは党大会や両院議員総会で選ばれた日だが、前の総裁の任期満了に合わせた総裁選では、任期が前任の任期満了の翌日から始まるので、選ばれた日より数日あとになる（例：岸田文雄は2021年9月29日の総裁選で選ばれ、10月1日に就任）。その場合は備考の「選出」に総裁選の日を書いた。
- 終了日は次の総裁の就任日にした。ただし大平正芳は在任中の1980年6月12日に死去し、7月15日に鈴木善幸が就任するまで西村英一副総裁が総裁を代行したので、終了日は死去の日にした（公式サイトの在任期間も6月12日まで）。
- 麻生太郎は2009年9月16日に総裁を辞任し、9月28日の総裁選で谷垣禎一が選ばれるまで総裁は空席だったが、公式サイトの在任期間（9月30日まで）に合わせて、終了日は次の総裁の就任日（10月1日）にした。
- 1955年11月15日の結党から1956年4月5日に鳩山一郎が初代総裁に選ばれるまでは総裁を置かず、鳩山一郎・緒方竹虎・三木武吉・大野伴睦の4人の総裁代行委員が党を率いた（緒方竹虎は1956年1月28日に死去し、2月10日から松野鶴平が加わった）。この期間は年表に入れていない。
- 代は公式サイトの数え方で、安倍晋三は第21代と第25代の2回ある。
- 総理大臣にならなかった総裁は、第16代の河野洋平（細川・羽田内閣のときの野党の総裁で、村山内閣では与党の総裁だったが首相は社会党の村山富市）と、第24代の谷垣禎一（民主党政権のときの野党の総裁）の2人。区分で分けてある。
- 2024年9月27日の総裁選で石破茂が決選投票で高市早苗を破り、2025年10月4日の総裁選（石破茂の退陣表明に伴うもの）で高市早苗が決選投票で小泉進次郎を破った。高市早苗の任期は石破茂の残りの任期の2027年9月まで。2026年10月30日の時点で総裁選は行われておらず、高市早苗が在任中。
