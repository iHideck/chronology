## 注記

- 代・氏名・読み・就任日・退任日は、日本銀行「歴代総裁」のページの値。和暦の日付を西暦に直した。
- 同じ人が2度務めた井上準之助（第9代・第11代）と新木栄吉（第17代・第19代）は、代ごとに1行ずつにした。任期の満了で続けて再任された一萬田尚登・山際正道・黒田東彦は、日本銀行のページと同じく1つの代で1行にした。
- 2008年3月20日から4月9日までは総裁が空席で、副総裁の白川方明が総裁の職務を代行した。この間は空白にした。
- 日本語版 Wikipedia と Wikidata は、富田鐵之助の就任を1888年2月22日、市来乙彦の退任を1927年5月9日としている。
- 読みの姓と名の区切りは、日本語版 Wikipedia の記事に合わせた。池田成彬の読みは日本銀行のページの「いけだ せいひん」で、日本語版 Wikipedia は「いけだ しげあき」。
- 前職は、総裁になる前に最後に就いていた主な職で、相談役や監務（三菱の相談役にあたる職）は除いた。人名事典（コトバンク）と日本語版 Wikipedia の記事を照らし合わせて決めた。前川春雄は『日本銀行百年史』の年表、植田和男は日本銀行の履歴のページでも確かめた。山本達雄の日本銀行理事と、澄田智の日本銀行副総裁は、日本語版 Wikipedia の記事だけによる。
- 川田小一郎は1885年に三菱の第一線を退き、1889年に総裁になった。池田成彬は1936年に三井合名会社を定年で退き、翌年に総裁になった。
- 岩崎彌之助が三菱の社長を甥の岩崎久弥に譲った年は、日本語版 Wikipedia では三菱合資会社を設けた1893年（その後は監務）、百科事典マイペディアでは1896年。
- 高橋是清は、日本銀行副総裁のまま1906年から横浜正金銀行頭取を兼ねていた。
- 在任日数は、退任日と就任日の差の日数。
