## 注記

- 開始日は践祚（皇位を継いだ日）、終了日は譲位・崩御などで皇位を離れた日で、即位礼の日ではない。践祚と即位の区別がない第49代光仁天皇までは、日本語版 Wikipedia の在位期間の始まり（即位の日）を開始日とした。践祚と日を隔てて即位した最初の天皇は第50代桓武天皇。
- 日付は日本語版 Wikipedia の各天皇の記事の在位期間に書かれた西暦で、1582年10月15日より前はユリウス暦、それ以後はグレゴリオ暦（明治5年までは旧暦の日付からの換算）。記事の和暦の日付はすべて国立天文台「日本の暦日データベース」で換算し直し、記事の西暦と合うことを確かめた。
- 記事どうしで日付が食い違うものは、記事の本文や前後の天皇の記事と合うほうを採った。東山天皇の践祚は貞享4年3月21日（1687-05-02。基礎情報の3月25日は採らない）、後土御門天皇の崩御は本文の明応9年9月28日（1500-10-21。基礎情報の和暦9月29日は西暦と合わない）。「天皇の一覧」の表と各天皇の記事が食い違う光孝天皇の践祚（元慶8年2月4日、0884-03-04）と、後伏見天皇の譲位・後二条天皇の践祚（正安3年1月21日、1301-03-02）は記事に合わせた。表が即位の日を載せている清和天皇は践祚の日（天安2年8月27日、0858-10-07）にした。
- 重祚した皇極天皇（第35代）と斉明天皇（第37代）、孝謙天皇（第46代）と称徳天皇（第48代）は別の項目にした。同じ人物なのでリンク先は同じ。
- 南北朝時代は、南朝の天皇（後醍醐・後村上・長慶・後亀山）を含む歴代の天皇を本流の段、北朝の天皇（光厳・光明・崇光・後光厳・後円融と、南北朝合一までの後小松）を北朝の段に置いた。北朝の5人は歴代の代数に数えないので、代は「北朝第N代」とした。後醍醐天皇の在位は1318年から1339年まで通して数え、1331〜1333年は北朝の光厳天皇と重なる。
- 後小松天皇は、北朝第6代として践祚した1382-05-24から南北朝合一の1392-11-19（明徳3年閏10月5日）までを北朝の段、それ以後を第100代として本流の段の別の項目にした。
- 本流の段で前の天皇の終了日と次の天皇の開始日が7日以上離れている期間（崩御や譲位から、次の天皇の践祚、光仁天皇までは即位までの空位）：0654-11-24〜0655-02-14（孝徳→斉明）、0661-08-24〜0668-02-20（斉明→天智）、0672-08-21〜0673-03-20（弘文→天武）、0686-10-01〜0690-02-14（天武→持統）、0707-07-18〜0707-08-18（文武→元明）、0770-08-28〜0770-10-23（称徳→光仁）、1242-02-10〜1242-02-21（四条→後嵯峨）、1428-08-30〜1428-09-07（称光→後花園）、1500-10-21〜1500-11-16（後土御門→後柏原）、1526-05-18〜1526-06-09（後柏原→後奈良）、1557-09-27〜1557-11-17（後奈良→正親町）、1654-10-30〜1655-01-05（後光明→後西）、1762-08-31〜1762-09-15（桃園→後桜町）、1779-12-16〜1780-01-01（後桃園→光格）、1846-02-21〜1846-03-10（仁孝→孝明）、1867-01-30〜1867-02-13（孝明→明治）。
- このうち 0661-08-24〜0668-02-20 は中大兄皇子（天智天皇）が、0686-10-01〜0690-02-14 は持統天皇が、即位しないまま政務をとった称制の期間で、在位には含めていない。0672-08-21〜0673-03-20 は壬申の乱で弘文天皇が敗れてから天武天皇が即位するまで。
- 本流の段で1〜2日だけあいているもの：0672-01-07〜0672-01-09（天智→弘文）、1155-08-22〜1155-08-23（近衛→後白河）、1308-09-10〜1308-09-11（後二条→花園）、2019-04-30〜2019-05-01（明仁→今上）。前の天皇の崩御・退位の翌日や翌々日に次の天皇が立ったため。
- 本流の段では安徳天皇（〜1185-04-25）と後鳥羽天皇（1183-09-08〜）の在位が重なる。平家が安徳天皇と三種の神器を伴って都を離れたのち、後鳥羽天皇が神器のないまま践祚したため。
- 北朝の段で北朝の天皇がいない期間：1333-07-07〜1336-09-20（光厳天皇が後醍醐天皇に廃されてから光明天皇の践祚まで）、1351-11-26〜1352-09-25（正平一統で崇光天皇が廃されてから後光厳天皇の践祚まで）。
- 長慶天皇の践祚・譲位と後亀山天皇の践祚は日付が分からないので月までにし、「推定・諸説あり」とした（長慶天皇の践祚は正平23年3月、譲位は弘和3年冬と推定されており、1383年12月とした）。弘文天皇は実際に即位したかどうかに議論があるので「推定・諸説あり」とした。
- 崩御が伏せられた天皇は、日本語版 Wikipedia の記事の在位期間に合わせた。後桃園天皇は崩御の発表に合わせた安永8年11月9日（1779-12-16）まで、仁孝天皇は崩御の日（弘化3年1月26日、1846-02-21）まで。実際の崩御日・公表日は備考に書いた。
- 第125代は追号がまだないため、名前を「上皇（明仁）」、略称を「明仁」とした。今上天皇（第126代）は略称を「今上」、終了日を空欄（在位中）とした（2026年10月30日時点）。
- 読みは「天皇の一覧」と宮内庁「天皇系図」により、現代仮名遣いで書いた。諱は「天皇の一覧」と各天皇の記事により、改名などで複数あるものは「・」でつないだ。
