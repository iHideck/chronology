# 日本銀行総裁と政策金利

日本銀行が開業した1882年から今日までの、歴代総裁と政策金利を、総理大臣と景気の波と同じ時間軸に並べた年表です。金利は、変わった日から次に変わる日まで同じ高さの線で描いています。1990年代半ばまでは公定歩合の上げ下げが金融政策の中心で、その後は短期の市場金利（無担保コールレート）を目標にするようになり、1998年からは数字の誘導目標を示しています。ゼロ金利、量的緩和、マイナス金利を経て、2024年からは利上げが続いています。

**動く版：[ihideck.github.io/chronology/policy-rates](https://ihideck.github.io/chronology/policy-rates/)**　データ：[policy-rates.csv](policy-rates.csv)（[書き方](../README.md#年表の足し方)）

## 注記

- 金利は、変わった日から次に変わる日まで同じ高さの線で描いた。誘導目標の線が途切れているところは、金利の目標がなかった時期（量的緩和など）。
- 1行に1回の変更。日付は、その金利が効き始めた日（実施日）。決定日は、決めた日（政策委員会・金融政策決定会合）が実施日と違うときだけ書いた。
- 公定歩合は、日本銀行の時系列統計（日次）で値が変わった日と、その値。1906年5月までは本店の、1906年7月からは全店の商業手形割引歩合（1910年3月6日までは当所割引歩合と他所割引歩合が分かれていて、当所割引歩合）、1969年9月からは商業手形の割引歩合と国債などを担保とする貸付の利子歩合を同じにした率、2001年1月4日からは基準割引率および基準貸付利率。2006年7月以降の公表文は、補完貸付の金利である「基準貸付利率」と呼んでいる。
- 1969年8月までは、公定歩合を日歩（元金100円あたり1日の利息。銭・厘・毛）で決めていた。金利（%）は、時系列統計にある年利の換算値（日歩×365。例：日歩2銭＝年7.30%）で、決めた日歩は内容に書いた。1969年9月1日からは年利で決めている。
- 公定歩合の値と日付は、時系列統計を『日本銀行百年史』の公定歩合の表（1882〜1972年）と、日本銀行の公表データの CSV（1955年〜）で照らし合わせ、すべて一致した。1973年以降の変更は、日本銀行の公表文で決定日と実施日を確かめた。1972年までは決定日を確かめていないので、決定日を空にした。
- 短期金利の誘導目標は、日本銀行が金融市場調節方針で示した無担保コールレート（オーバーナイト物）の目標。2016年2月16日から2024年3月20日までは、日本銀行当座預金のうち政策金利残高に付けた▲0.1%のマイナス金利（2016年9月21日からは、長短金利操作付き量的・質的金融緩和の短期金利の目標）。
- 誘導目標は、数字の目標を初めて示した1998年9月9日から。1995年7月から1998年9月までは、短期の市場金利を公定歩合を下回る水準に促す方針で、数字の目標はなかった。
- 「0〜0.1%程度」のように範囲で示した目標は、範囲の真ん中（0.05%）にし、元の文言を内容に書いた。「概ねゼロ%」は0%にした。1999年2月12日の「できるだけ低めに」は、公表文にある当初の目標の0.15%にした（その後の公表文は、この方針を「ゼロ金利政策」と呼んでいる）。
- 2001年3月19日から2006年3月8日まで（量的緩和政策。目標は日本銀行当座預金残高）と、2013年4月4日から2016年2月15日まで（量的・質的金融緩和。目標はマネタリーベース）は、金利の目標がなかった。それぞれの始まりの日に、金利を空にした誘導目標の行を置いた。
- 誘導目標の実施日は、2024年3月以降は公表文が「翌営業日から適用」と定めた日。それより前は、公表文に適用日の定めがないか「公表後直ちに実施」なので、決定日にした。マイナス金利は、公表文のとおり2016年2月16日からの準備預金の積み期間から。
- 2026年10月30日の金融政策決定会合（据え置き）までの決定を含む。
