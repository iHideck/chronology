# オリンピックと万博

1851年のロンドン万博から、開催地の決まっている2034年の冬季オリンピックまで、オリンピックと国際博覧会（万博）の開催地を、戦争と同じ時間軸に並べた年表です。2度の世界大戦では、オリンピックが3度中止になりました。1940年の東京大会は、日中戦争のために返上されています。

**動く版：[ihideck.github.io/chronology/olympics-expos](https://ihideck.github.io/chronology/olympics-expos/)**　データ：[olympics-expos.csv](olympics-expos.csv)（[書き方](../README.md#年表の足し方)）

## 注記

- オリンピックは、夏季が1896年アテネから、冬季が1924年シャモニー・モンブランから、開催地の決まっている2032年・2034年の大会まで。戦争で中止になった大会（夏季1916年・1940年・1944年、冬季1940年・1944年）も入れた。1906年アテネの中間大会は、IOC が公式の大会と認めていないので入れていない。
- 国際博覧会は、博覧会国際事務局（BIE）の公式の一覧にある登録博（World Expos）と認定博（Specialised Expos）の、1851年ロンドンから2030年リヤドまで。園芸博とミラノ・トリエンナーレは入れていない。1988年の条約改正（1996年から適用）より前の「一般博」は登録博、「特別博」は認定博とし、BIE の今の分類に合わせた。BIE の設立（1928年）より前の博覧会は、BIE が World Expos に入れているものを登録博にした。
- 開会日（博覧会は開幕日）の点で描く。閉会日・状態・回・都市・国・備考は、吹き出しと一覧表に出る。
- 名前は、オリンピックは JOC の表記（第N回オリンピック競技大会、第N回オリンピック冬季競技大会）。冬季の中止された2大会は回が付かないので、日本語版 Wikipedia の記事名。博覧会は、経済産業省のページにある名称（2020年ドバイ、2025年日本、2027年ベオグラード、2030年リヤドなど）はその名称、ほかは日本語版 Wikipedia の記事名。
- 回は IOC の数え方。夏季はオリンピアード（4年間）の番号なので、中止された1916年・1940年・1944年にも第6・12・13回が付く。冬季は開催順に番号が付くので、中止された1940年・1944年には付かず、1948年が第5回（オリンピック憲章 規則6の付属細則）。
- 国は、開催当時の国名でなく今の国名で書いた（1972年ミュンヘンは西ドイツ、1980年モスクワはソ連、1984年サラエボはユーゴスラビアだった）。
- オリンピックの開会日・閉会日は、IOC のページの日付を基本にし、日本語版と英語版の Wikipedia が同じ日を挙げていればそれを採った。IOC の日付が現地の日付と1日違うもの（夏季は1904年・1956年・1964年・1968年・1976年・1988年・1996年、冬季は1972年・1998年・2018年）は、Wikipedia・Olympedia・JOC が一致する日にした。夏季の1912年・1920年・1924年・1928年は、IOC が最初の競技の日から大会の期間を数えるため、開会式・閉会式の日を採り、IOC の期間は備考に書いた。
- 中止になった大会は、閉会日を空にした。開始日は、開会の予定日が分かる1940年の東京（9月21日）と札幌（2月3日）はその日、分からない大会は年だけにした。1940年の2大会は、返上された東京・札幌の行にして、その後の変更先は備考に書いた。略称には、中止になった大会に「（中止）」、延期された2020年東京に「（延期）」を付けた。
- 状態の「延期して開催」は、開催の予定が1年延びた2020年東京と2020年ドバイ。実際の開会日・開幕日を開始日にした。ほかに日程が動いた1975年沖縄（開幕が4か月延びた）は備考に書いた。
- 博覧会の会期は BIE の公式の一覧の日付を採った。ただし、BIE のページの中で食い違う1900年パリ（本文は開幕4月14日、会期の欄は4月15日）、閉幕の年が誤っている1936年ストックホルム（会期の欄は1935年6月1日）、日本語版と英語版の Wikipedia が11月3日としている1974年スポーケン（BIE は11月2日）は、一致する日付にした。1851年ロンドンの閉幕日（10月11日）は一般公開の最終日で、閉会式は10月15日。会期が2期に分かれる1933年シカゴと1939年ニューヨークは、最初の開幕日と最後の閉幕日を書いた。
