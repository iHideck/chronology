# 征夷大将軍と執権

794年の大伴弟麻呂から1867年の徳川慶喜までの征夷大将軍と、鎌倉幕府の執権の在職期間を、肖像つきで天皇の在位と同じ時間軸に並べた年表です。鎌倉幕府の4代目からの将軍は京都から迎えた摂家や皇族で、そのあいだ政治を動かした執権の北条氏と並べて読めます。

## 注記

- 征夷大将軍は、大伴弟麻呂（794年）から徳川慶喜（1867年）まで。幕府より前の将軍（大伴弟麻呂・坂上田村麻呂・文室綿麻呂）と、建武政権の護良親王・成良親王を含む。執権は北条時政から北条守時までの16代。同じ人が2度務めたもの（坂上田村麻呂・文室綿麻呂・足利尊氏・足利義稙）は2行にした。
- 開始日は征夷大将軍に任じられた日（将軍宣下）と執権に就いた日、終了日は辞任・解任・死去などで職を離れた日。離れ方は「終わり方」の列に書いた。将軍のいない期間は行を作っていない。
- 江戸幕府の4代家綱から14代家茂までは、勅使が江戸に下り、江戸城で将軍に宣旨を授けた。開始日はこの江戸城で宣旨を受けた日にした（史料綱文による）。それより前に朝廷で任じた日が綱文にあるものは、家綱が慶安4年7月13日、綱吉が延宝8年7月18日、吉宗が享保元年7月18日、家斉が天明7年3月6日、家慶が天保8年8月5日、家定が嘉永6年10月23日、家茂が安政5年10月25日で、日本語版 Wikipedia「征夷大将軍」の一覧の多くはこの日を載せている。一覧の家綱（慶安4年7月26日）・家宣・家継・家重・家治の日付は、綱文では確かめられなかった。
- 鎌倉幕府に廃されて京都に送られた将軍（藤原頼嗣・宗尊親王・惟康親王・久明親王）の終了日は、征夷大将軍を辞した日（日本語版 Wikipedia の各記事の官歴。綱文の同じ日に、廃位を朝廷に願い出た・京都に着いた・京都へ発ったなどの記事がある）。宗尊親王は文永3年7月4日に北条時宗らに廃され、7月20日に京都に着いた。
- 足利義稙の1度目は、明応の政変で細川政元が清晃（のちの足利義澄）を立てた明応2年4月22日を終了日にし、「推定」とした。朝廷が解任した記録は見当たらない。日本語版 Wikipedia の一覧は、幽閉先から越中へ逃れた6月29日を解任の日としている。
- 足利尊氏は、正平一統が破れた正平7年閏2月6日に南朝に解任され（南朝は同じ日に宗良親王を征夷大将軍とした）、観応3年6月27日に北朝のもとで還任したとして2行にした。還任の日は日本語版 Wikipedia の一覧によるもので、ほかの資料では確かめられなかったので「推定」とした。
- 建武政権・南朝の将軍のうち、南朝の興良親王（延元4年＝1339年ごろ）と宗良親王（正平7年＝1352年）は、職を離れた時期を示す資料が見つからないため入れていない。宗良親王の子という尹良親王は、実在が疑問視されているため入れていない。足利尊氏が建武2年（1335年）に任じられたのは征東将軍なので入れていない。
- 源義仲は『史料綜覧』などで征夷大将軍とされてきたが、日本語版 Wikipedia の「征夷大将軍」「源義仲」の記事は征東大将軍とし、源頼朝の任官のときに『山槐記』が義仲の「征東大将軍」を凶例として退けたと記す。同じく征東大将軍だった藤原忠文（940年）とともに入れていない。
- 大伴弟麻呂は延暦10年（791年）に征東大使となり、征夷大将軍としては延暦13年1月1日に節刀を賜ったのが初めて見える記録なので、この日を開始日にして「推定」とした。文室綿麻呂の職名は征夷将軍。坂上田村麻呂の2度目と文室綿麻呂は職を離れた日の記録がなく、田村麻呂の2度目は大納言になった大同5年9月10日（日本語版 Wikipedia の一覧）、綿麻呂の1度目は征討を終えて兵の削減が許された弘仁2年閏12月11日、2度目は一覧の弘仁7年を終了日にし、いずれも「推定」とした。
- 北条時政は、建仁3年10月9日に大江広元と並んで政所別当になった日を開始日にし、「推定」とした（執権一覧は建仁3年9月とする）。北条義時の開始日は、時政が伊豆に退いた元久2年閏7月20日（承元3年＝1209年とする説もある）。
- 資料で日付が分かれるものは、綱文と記事の多いほうを採った。源頼家の就任は『大日本史料』の建仁2年7月23日（記事は22日）、足利義勝の就任は『史料綜覧』と記事の本文の嘉吉2年11月7日（一覧と記事の官歴は11月17日）、北条経時の就任は仁治3年6月16日（記事の官歴は15日）、北条煕時の辞任と北条基時の就任は正和4年7月12日（それぞれの記事は11日）、北条師時の死去は応長元年9月22日（執権一覧は21日）、北条高時の出家は正中3年3月13日（執権一覧は2月13日）。
- 死去を伏せた将軍は亡くなった日を終了日にした（家慶・家定・家茂）。徳川家治は『徳川実紀』と綱文が死去の日とする天明6年9月8日（喪を発した日）にし、「推定」とした（8月25日に亡くなったとする説などがある）。徳川家定の死去は安政5年7月6日（史料綱文は7月4日）。
- 源頼朝は、『尊卑分脈』に建久5年（1194年）に征夷大将軍を辞したとあるが、死去までとした。足利義昭は元亀4年（1573年）に京都を追われたあとも、天正16年1月13日に出家するまで征夷大将軍だった。徳川慶喜は慶応3年10月に大政奉還をし、12月9日の王政復古の大号令で将軍職の辞職が認められ、幕府が廃止された。
- 和暦は国立天文台「日本の暦日データベース」で西暦に直した。1582年10月15日より前はユリウス暦、それ以後はグレゴリオ暦。日本語版 Wikipedia の西暦表記・史料綱文の日の干支と照らし合わせ、その月の1日が天文計算の新月の日か前後1日にあたることを確かめた。
- 月までしか分からない日付は月まで、年までしか分からない日付は年までにし、「推定」とした。月までの終了日は、その月の末日を含む西暦の月にした。
- 「開始日（和暦）」「終了日（和暦）」は、その日に使われていた元号で書いた。南北朝時代は北朝の元号（建武政権の将軍は後醍醐天皇の元号、正平一統の中の尊氏の解任は南朝の正平）。鎌倉幕府が滅んだ1333年の日付は、幕府が使っていた正慶で書いた。
- 代は幕府ごとの代数（鎌倉の将軍1〜9、室町1〜15、江戸1〜15、執権1〜16）。足利尊氏は2度目も第1代、足利義稙は2度目も第10代。名前は日本語版 Wikipedia の記事名に合わせ、改名した人は最後の名で書いた（足利義稙の1度目のころの名は義材）。読みは日本語版 Wikipedia の記事と「鎌倉幕府の執権一覧」による。
- ほかの列の定義・注記・出典は、それぞれの年表に載せています：[歴代天皇](../emperors/)
