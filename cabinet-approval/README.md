## 注記

- 時事通信社の時事世論調査（実査は中央調査社）の内閣支持率と不支持率。調査は1960年7月から毎月続くが、この年表は毎月の結果を中央調査社のサイトで読める2004年9月から。
- 毎月1回、全国の20歳以上（2016年11月からは18歳以上）の男女2000人を、調査員が訪ねて面接で聞く。2020年5月と6月だけは郵送法。
- 質問は「あなたは〇〇内閣を支持しますか」。面接では選択肢を示さず、「支持する」「支持しない」のどちらとも答えない人は「わからない」に数える。この3つで100%になる（四捨五入で合計がずれる月がある）。
- 郵送法の2020年5月と6月は、質問票で「支持する」「支持しない」を選ぶ形にしたため、面接の月より不支持率が高く出たとみられる。
- 2020年4月は新型コロナウイルスの感染拡大で調査が中止され、値がない。2006年9月の不支持率は資料に記載がない。
- 年月は調査の月。調査は月の上旬から中旬の4日間で、調査日はその始まりの日（郵送法の月は質問票を投函した日）。
- 内閣と首相は、調査日に在任していた内閣とその首相。内閣の名前は首相官邸「歴代内閣」の書き方で、改造内閣は分けない。2010年6月は、菅直人の首相指名の直後で内閣の発足の前に始めた調査だが、菅内閣について聞いたので菅内閣とした。
- 支持率と不支持率は中央調査報に載った値。2026年10月は、まだ中央調査報に載っていないため、時事ドットコムの記事の値。
- 被災地などを除いて調査した月は、備考に書いた。
- ほかの列の定義・注記・出典は、それぞれの年表に載せています：[歴代総理大臣と世界の首脳](../prime-ministers/)、[国政選挙と投票率](../elections/)
