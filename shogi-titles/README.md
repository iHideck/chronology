## 注記

- 名人は1937年に始まった実力制の名人（第1期〜）、竜王は1988年に始まった竜王戦（第1期〜）。同じ人が続けて保持した期間を1件にまとめた（例：大山康晴の第18期〜第30期）。「期」は、その期間に保持した期。
- 開始日はそのタイトルを獲得した番勝負の決着日（最終局の日。2日制の対局は2日目）、終了日はそのタイトルを失った日で、次の保持者の開始日と同じ日にした。現在の保持者は終了日を空欄にした。
- 第1期名人の木村義雄は番勝負がなく、名人決定特別リーグの最終局（千日手による指し直し局、1937年12月5・6日）に勝って名人が確定した日を開始日にした。名人への就位は1938年。
- 1977年度は名人戦の主催者が移る問題で名人戦が行われず、中原誠の名人が続いた（第36期は1978年に実施）。
- 決着日は Wikipedia の各期の記事（日本将棋連盟『将棋年鑑』を出典とする基本情報欄と対局詳細の表）によった。千日手・持将棋の指し直しがある期は、指し直し局の日を決着日にした。2011年以降の名人の交代（第69・72・74・77・78・81期）と2013年以降の竜王の交代（第26・27・28・30・31・32・34期）は、日本将棋連盟の各期の番勝負ページの日程・勝敗とも一致することを確かめた。
- 2026年10月30日時点：名人は藤井聡太（第84期名人戦で糸谷哲郎八段に4連勝して防衛）。竜王戦は第39期七番勝負（藤井聡太竜王対服部慎一郎七段）が進行中で藤井の2勝0敗のため、藤井を現保持者として終わりを空欄（継続中）にした。第39期の結果が出たら更新が必要。
- 世襲名人は、江戸時代の家元三家（大橋本家・大橋分家・伊藤家）から出た一世〜十一世と、推挙による十二世小野五平・十三世関根金次郎。開始日は襲位・就位の年（年しか分からないので年だけ）、終了日は没日または退位の日。名人が空位だった時期（1761〜1789年、1809〜1825年、1843〜1879年、1893〜1898年）は空いている。年だけの開始日は、同じ年の前の名人の終了日と見た目で重なることがある。
- 世襲名人の没日は Wikipedia の各人の記事にある西暦換算（グレゴリオ暦）を使い、天文計算による旧暦換算でも一致することを確かめた。初代大橋宗桂を1612年に一世名人とするのは日本将棋連盟の見解で、異説があるため「推定・諸説あり」とした。三代大橋宗与の襲位は享保8年末（グレゴリオ暦では1723年末〜1724年初め）のため「推定・諸説あり」とした。
