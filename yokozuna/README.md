## 注記

- 第4代の谷風から第75代の大の里まで72人（現役は第74代豊昇龍と第75代大の里）。代数と顔ぶれは日本相撲協会の歴代横綱一覧に従った。
- 第1〜3代（明石志賀之助・綾川五郎次・丸山権太左衛門）は協会の一覧には載っているが、伝説上の存在で、当時は横綱という制度もなかったとするのが通説のため年表に入れていない（江戸時代の横綱の数え方は、1900年に陣幕久五郎が建てた横綱力士碑にもとづく）。
- 開始日は横綱に昇進した時点。日が分かるものはその日にした：谷風・小野川は吉田司家から横綱免許を受けた日（寛政元年11月19日＝1790年1月4日）、男女ノ川は番付編成会議で推挙された日、第41代千代の山以降は日本相撲協会の番付編成会議・理事会で横綱昇進が決まった日（昇進伝達式の日）。日が分からないもの（第6〜33代、第35〜40代、第50代佐田の山、第57代三重ノ海）は、協会のプロフィールにある「新横綱」の場所の月（年月まで）にした。
- 終了日は引退した日にした：本人が引退を表明・声明した日、または引退届が受理・承認された日（白鵬は2021年9月30日の理事会承認、双羽黒は1987年12月31日の廃業届受理）。現役のまま亡くなった谷風・玉錦・玉の海は亡くなった日。日が分からないもの（第5〜31代、第34〜40代）は、協会のプロフィールにある「引退」の場所（最後の場所）の月。現役の豊昇龍・大の里は終了日を空欄にした。
- 江戸時代（第4〜13代）の場所の月は旧暦。天文計算による旧暦換算（Wikipedia に載っている和暦と西暦の対応16例ですべて一致することを確かめた）で、その月の15日にあたるグレゴリオ暦の月を使い、「推定・諸説あり」とした。
- 日付が推定のもの、資料によって1〜2日ずれるものも「推定・諸説あり」として、備考に根拠を書いた（吉葉山・玉の海・北の富士・隆の里・旭富士の昇進、大乃国・旭富士の引退）。
- 江戸〜大正の横綱は、横綱免許の時期と新横綱の場所が数か月ずれることがある。免許の時期、五条家・吉田司家・大阪相撲の免許の違いは備考に書いた。秀の山の免許には1845年説と1847年説がある。大阪相撲の横綱（若島・大木戸・大錦（大五郎）・宮城山）の昇進・場所は大阪相撲のもの。
- 幕内優勝は日本相撲協会の歴代横綱一覧の回数（2026年10月30日時点。豊昇龍2回・大の里6回）。優勝制度ができた1909年（明治42年）6月より前の分は協会の回数がないため、Wikipedia の各力士の記事にある優勝相当成績の回数を「制度前（優勝相当成績N回）」と書いた。大阪相撲での優勝は分けて書いた。
- 出身と部屋は日本相撲協会の歴代横綱のページの記載による。部屋は所属の移り変わりを「→」でつないだ（（大坂）（大阪）（京都）はその地の相撲の部屋）。
- 同じ四股名の横綱は（初代）（二代）や下の名前を付けて区別し、略称に四股名だけを入れた。第66代の若乃花は一般に3代目若乃花と呼ばれるので（三代）とした。
- 区分は横綱に昇進した時代（元号）。境目は明治1868年10月23日、大正1912年7月30日、昭和1926年12月25日、平成1989年1月8日、令和2019年5月1日。第13代鬼面山は明治2年の昇進なので明治。
- 2025〜2026年の動き：第73代照ノ富士が2025年1月17日に引退し、豊昇龍が2025年1月29日、大の里が2025年5月28日に横綱昇進した。2026年10月26日発表の11月場所の番付でも横綱はこの2人で、2026年10月30日までに新しい昇進・引退はない。
